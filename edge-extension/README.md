# DeskFish · Edge 隐形播放器、漫画与电子书

把当前网页中的图片或视频临时替换为 Bilibili 横屏视频、Bilibili/虎牙直播、真实桌面游戏窗口、离线小游戏或漫画阅读器，也可以把一段网页文字替换为本地 TXT 电子书内容。虎牙公开直播由随包本地程序解析并通过回环地址短时代理，不会把直播内容写入磁盘。

## 安装

1. 将一体化 ZIP 解压到一个固定文件夹，不要直接在压缩包内运行。
2. 双击根目录的 `DeskFish.exe`。它会启动 DeskFish 自带的本地阅读引擎，并缩小到 Windows 托盘；不需要 Java、Python、Node、Docker、Suwayomi 或额外来源插件。
3. 在 Edge 地址栏打开 `edge://extensions/`，打开左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择一体化目录中的 `edge-extension` 文件夹。
5. 可将 DeskFish 固定到浏览器工具栏。使用“DeskFish 本地漫画源”时，请让 `DeskFish.exe` 保持运行。

`DeskFish.exe` 只监听本机地址 `127.0.0.1:47653`，不会开放局域网端口。首次运行若 Windows SmartScreen 提示未知发布者，是因为当前测试版没有代码签名证书；确认文件来自本项目的压缩包后可选择继续运行。

## 使用

### 选择替换内容

扩展顶部的“替换内容”可选择：

- Bilibili 视频队列
- Bilibili 直播间：填写房间号或 `live.bilibili.com/房间号` 链接
- 虎牙直播间：填写房间号或 `huya.com/房间号` 链接，需要保持 `DeskFish.exe` 运行
- 五子棋：15×15 本地人机对战，可悔棋
- 2048：支持方向键和画面内方向按钮
- 贪吃蛇：支持方向键、WASD 和画面内方向按钮
- 漫画阅读：本地漫画、MangaDex、Komiic 中文在线漫画或自建漫画服务器

三个小游戏都随扩展离线运行，不会打开第三方游戏网站，也不需要登录。

小游戏会监听替换区域本身的尺寸变化。区域较小时自动进入紧凑模式：隐藏标题、说明和方向按钮，让棋盘或画面占满可用空间，只保留小型悔棋/重开按钮；放大后恢复完整界面。

### 建立 Bilibili 播放队列

任选一种方式：

- 打开 Bilibili 视频、UP 主、合集或搜索结果页面，打开扩展并点击“收集当前 Bilibili 页面”。扩展会收集当前页面 DOM 中已有的 BV 视频链接。
- 在输入框中粘贴普通 Bilibili 视频链接、BV 号或 `b23.tv` 短链，每行一个，然后点击“加入队列”。

### 替换网页元素

1. 打开目标网页。
2. 点击扩展中的“选择图片或视频”，或按 `Alt+Shift+V`。
3. 移动鼠标并点击要替换的图片或视频。
4. 所选内容会保持该区域的原尺寸。默认开启“悬停才显示”：鼠标在该区域内时显示播放器或游戏，移开后立即盖回原网页图片。

悬停隐藏不会销毁 iframe，也不会刷新播放器。普通 Bilibili 视频移开时暂停，回来时从原会话继续；Bilibili 与虎牙直播只隐藏画面，始终保持播放连接。贪吃蛇会同步暂停。若关闭“悬停才显示”，替换内容会一直可见。

扩展会自动向上识别完整的媒体区域，而不只是最里面的 `<img>`：网站叠加在图片上的标题、悬停预览容器和动态视频层会一并接管。伪装层使用不带网页事件监听器的静态克隆，Bilibili 等网站自身的悬停预览不会抢回画面。

### 桌面游戏窗口贴片

1. 把游戏切换为窗口化或无边框窗口模式，并保持 `DeskFish.exe` 运行。
2. 在 DeskFish 的“窗口贴片”区域，把游戏窗口拖到虚线投放框内松开；也可以从上方列表直接选择。拖入时 DeskFish 会短暂置顶投放框，并按开始拖动时的前台进程识别窗口。
3. 在扩展“替换内容”中选择“桌面游戏窗口”，点击“刷新窗口识别状态”，再选择网页图片/视频或创建独立区域。
4. 鼠标进入网页区域时，DeskFish 会把真实窗口去边框并贴到对应屏幕位置；点击后可以直接操作游戏。移出区域会隐藏游戏并恢复原网页图片，游戏进程本身不会被关闭。
5. 恢复页面、切换来源、关闭页面或退出 DeskFish 时会释放贴片并恢复游戏原有位置、尺寸、边框与可见状态。任何时候都可以按 `Alt+Shift+G` 紧急隐藏。

这是 Windows 原生窗口覆盖在网页坐标上的实现，不是把游戏画面复制进 DOM。独占全屏游戏、管理员权限高于 DeskFish 的窗口，以及带反作弊或禁止改窗样式的游戏可能无法使用；不要在联机反作弊游戏中启用。

### 创建独立区域

如果页面没有合适的图片，直接点击“创建左侧独立区域”：

1. 扩展会参考文章主体左边距，在页面左侧生成一个 16:9 区域；没有足够空白时使用通用尺寸，并允许拖动。
2. 默认显示一张低调的数据概览占位图，悬停后显示当前选中的视频、直播、游戏或漫画。
3. 按 `Alt+Shift+H` 显示控制条，拖动 `⠿` 移动区域；开启控制条后还可拖动右下角调整大小。
4. 点击控制条的 `×`，或使用“恢复当前页面”，会完整移除这个独立区域。

### 浏览器右下角广告窗

点击“打开右下角浏览器广告窗”。也可以在 Edge 扩展快捷键页为“打开或聚焦右下角浏览器广告窗”分配 `Alt+Shift+A`：

1. 扩展会在当前 Edge 窗口右下角创建一个独立的浏览器小窗。它不注入网页，所以切换标签页、刷新或访问其他网站时仍然保留。
2. 默认显示仿老式页游的“一刀 999”广告封面；鼠标移入后显示当前选择的视频、直播、小游戏或漫画，移开时立即恢复封面。普通视频暂停，直播继续播放。点击内层播放器造成的焦点切换不会再被误判为移开。
3. 再次点击入口或使用已分配的快捷键会聚焦已经打开的广告窗，不会重复创建多个。
4. 广告封面使用扩展原创背景和 Openclipart 公有领域战士素材合成，完整来源见 `THIRD_PARTY_NOTICES.md`，不需要联网加载图片。

这是 Edge 扩展能创建的独立 `popup` 浏览器窗口，不属于任何网页。受浏览器接口限制，扩展不能把任意图层画到地址栏、标签栏等浏览器外壳上，也不能强制窗口永远置顶；如果被其他完整窗口盖住，可再次点击入口或使用自行分配的快捷键重新聚焦。

快捷键：

- `Alt+Shift+→`：下一条，即使焦点位于播放器 iframe 中也能触发。
- `Alt+Shift+←`：上一条。
- `Alt+Shift+H`：显示或隐藏视频右上角控制条；控制条默认完全隐藏。
- 广告窗命令：可在 `edge://extensions/shortcuts` 中按需分配 `Alt+Shift+A`。
- 页面焦点位于播放器外部时，也可用 `J` / `↓` 和 `K` / `↑`。
- `Esc`：恢复原网页内容。

小游戏需要先把鼠标移入替换区域并点击一次，再使用方向键或 WASD；这样按键只作用于游戏，不会滚动外层网页。

### 漫画阅读

在“替换内容”选择“漫画阅读”，然后从下列来源选一本漫画或一个章节：

- **本地 CBZ / ZIP / 图片文件夹**：压缩包以 Blob 直接保存，打开时才逐页解码；图片文件夹分批写入 IndexedDB。不会因为漫画较大而把所有图片同时放进内存。
- **MangaDex 官方 API**：按漫画名搜索，选择语言和章节，阅读器使用 MangaDex At-Home 返回的省流页面。简中使用官方语言码 `zh`，繁中使用 `zh-hk`；如果所选语言暂无章节，可以切换为“全部语言”。页面底部保留 MangaDex 与汉化组署名。
- **Komiic 漫畫 · 中文在线**：可直接搜索并阅读中文漫画；站点标题以繁体中文为主，简体标题搜不到时可改用繁体。匿名访问存在每日图片额度，达到额度后可先登录 Komiic，或稍后再读。
- **DeskFish 本地漫画源**：由随包提供的 `DeskFish.exe` 在本机执行搜索、章节解析和图片转发。当前内置“包子漫画”“Komiic 中文漫画”“YY漫画”三个来源；扩展只调用统一的 `/api/v1` 接口，以后增加或修复站点来源时无需改动阅读器。无需另装来源插件。
- **Komga / Kavita / LANraragi**：使用它们提供的 OPDS 目录。Komga 常用 `/opds/v1.2/catalog`，LANraragi 常用 `/api/opds`；Kavita 请复制用户设置中生成的个人 OPDS 地址。
- **Suwayomi Server**：使用 `/api/opds/v1.2` 目录，因此不依赖扩展端复刻容易失效的站点来源插件。

选好后可像视频一样替换现有图片/视频、创建左侧区域，或放进右下角广告窗。方向键、鼠标滚轮、画面左右点击区以及 `Alt+Shift+←/→` 均可翻页；每个章节分别自动保存上次页码。工具栏里的“适宽/适页”可以切换显示方式。

漫画来源、搜索词、当前作品和整套章节目录会保存在扩展本地存储中。关闭扩展弹窗后再次打开，会直接恢复原来的来源和章节列表，不会退回“本地文件”。阅读器工具栏的 `«` / `»` 可切换上一话和下一话；在一话末页继续按右键、向下滚轮或点击右侧，也会自动进入下一话。当前话和页码同步保存，因此关闭阅读器或重启浏览器后会从上次位置继续。

DeskFish 本地漫画引擎会把搜索结果、章节目录和页面清单缓存到兼容旧版的 `%LOCALAPPDATA%\DeskFrame\manga-cache-v2`。退出并重开 `DeskFish.exe` 后仍能命中缓存；在线刷新失败时，近期缓存可以作为临时回退，超过 14 天的元数据会在启动时自动清理。阅读器会并发预读当前页前 5 页和后 5 页，最多只保留 11 个页面 Blob；翻页离开窗口或关闭阅读器时立即释放。

首次连接自建服务器时，Edge 会显示该服务器域名的访问授权。用户名和密码只写入 `chrome.storage.session`，关闭浏览器会话后清除；Kavita 的个人 OPDS 地址若已携带认证信息，用户名和密码可留空。

如果旧版快捷键仍然保留或快捷键被 Edge 占用，请点击扩展底部的“打开 Edge 快捷键设置”，或直接打开 `edge://extensions/shortcuts` 重新分配。

### TXT 电子书

1. 在扩展中点击“导入 TXT 电子书”。支持 UTF-8，并会在 UTF-8 解码失败时自动尝试 GB18030/GBK。没有固定的 3 MB 上限：扩展会边读取边自动识别章节、自动分片，不会一次把整本书放进内存；实际容量只受设备剩余磁盘空间影响。大文件导入完成前请保持扩展面板打开。
2. 点击“选择文字段落”，然后点击网页中的一段正文。
3. 扩展按该段落原有的非空白可见字符数，从电子书中取出相同数量的字符；中文标点也算一个字符。
4. “方向键翻页幅度”可设为 `1%`–`100%`，默认 `50%`。例如原段落有 30 个字符：设为 50% 时每次移动 15 个字符；设为 100% 时每次移动 30 个字符。
5. 替换完成后点击这段文字，即可启用滚轮阅读。鼠标悬停在该段文字上滚动时，每格按当前排版的一行字符数移动；鼠标移到段落外仍然正常滚动网页。
6. 按 `Esc` 或扩展中的“恢复当前页面”，恢复原段落及其原始子节点。

每次使用方向键或滚轮后，阅读位置都会自动保存；下次替换段落时从上次位置继续。电子书替换不会额外添加边框、背景或字号，继续使用原网页段落的样式。

本地 TXT 会识别常见的“第几章/回/卷”、序章、番外和英文 `Chapter` 标题，并在书籍信息下方显示章节选择器；识别不到时仍可作为单章“全文”阅读。在线小说默认使用智能搜索：运行 `DeskFish.exe` 时，中文关键词优先搜索起点中文网公开页面并补充中文维基文库结果；未运行 EXE 时仍可直连 Project Gutenberg、中文维基文库和英文 Wikisource。起点订阅章节会保留在目录中但不可点击，公开章节才会保存成本地分片。

## 设置说明

- “悬停才显示”默认开启。移开后显示的是原网页媒体元素，不是扩展生成的仿制占位图。
- 默认静音开启，以提高浏览器自动播放成功率。
- 如果关闭静音，Edge 可能会阻止自动播放，此时在播放器中点击播放即可。
- 弹幕默认关闭，可在扩展面板中开启。
- Bilibili 视频与直播使用官方 iframe 并关闭进入直播间、互动区、推荐、Logo、弹幕开关和多余控制组件。虎牙使用 DeskFish 本地 HLS 播放器，不加载平台网页组件，因此没有“试看结束”“进入直播间”按钮或平台弹幕。视频画面本身烧录的文字和主播贴图无法移除。

## 已知限制

- Edge 内部页面、扩展商店页面等不允许扩展注入脚本。
- 少数配置了严格内容安全策略的网站可能阻止第三方播放器加载。
- 虎牙直播依赖 `DeskFish.exe` 的本地公开房间解析器。它会自动回退多个 CDN；主播下播、房间限制、平台签名或页面结构变化仍可能导致暂时不可用。
- MangaDex 与 Komiic 的搜索结果、章节和图片取决于各自在线服务当时的内容、额度与可用状态。扩展不会转存漫画页。
- DeskFish 本地漫画源仍依赖对应漫画网站当前的页面结构与可用状态；站点改版后需要更新 DeskFish 内置适配器。它不是规避登录、付费或访问限制的工具。
- 自建漫画服务器必须已开启 OPDS；若服务使用自签名 HTTPS 证书，需要先在普通标签页中让 Edge 信任该证书。
- 抖音直播和推荐视频暂未加入：抖音目前没有面向普通 Web 扩展公开的稳定 iframe 播放器，公开的直播 SDK 是受准入控制的移动端能力。依赖抓流地址、Cookie、临时签名或反爬参数的 GitHub 实现容易失效，也不适合打包进浏览器扩展。
- 只能收集当前 Bilibili 页面中已经渲染到 DOM 的视频；滚动页面后再次收集，可以加入后续加载的条目。
- 页面自身如果重新渲染所选区域，播放器可能被移除；重新选择一次即可。
- Bilibili 和虎牙播放器位于跨域 iframe 中，普通按键在焦点进入播放器后无法被外层网页捕获，请使用浏览器级组合键。
- Edge 只允许扩展预设四组默认快捷键；电子书段落选择和电子书全局翻页命令可在 `edge://extensions/shortcuts` 中按需分配。段落选中后，普通左右方向键不需要额外配置。

## 权限

- `activeTab`、`scripting`：仅在用户点击扩展或使用快捷键时修改当前网页。
- `storage`、`unlimitedStorage`：仅在本机分片保存视频队列、播放设置、本地漫画、TXT 内容和阅读位置；后者用于取消浏览器对扩展本地存储的固定小容量配额。
- `*.bilibili.com`、`b23.tv`：收集 Bilibili 页面链接、加载播放器并解析用户粘贴的官方短链。
- `www.huya.com` 与虎牙 HLS CDN：只由本地 `DeskFish.exe` 请求公开房间元数据、短时播放清单和正在播放的分片；本地代理不会保存直播录像。
- `www.bilibili.com/blackboard/live`：加载用户选择的 Bilibili 官方活动直播播放器，并关闭不需要的入口与互动组件。
- `api.mangadex.org`、`uploads.mangadex.org`：搜索漫画、获取章节页面清单与封面。
- `komiic.com`：搜索 Komiic 漫画、读取卷/话和页面图片；`declarativeNetRequestWithHostAccess` 只为 Komiic 图片请求设置该章节页面所要求的来源页请求头。
- `www.gutenberg.org`：直连官方 OPDS 目录和用户所选公版书的纯文本文件。
- `zh.wikisource.org`、`en.wikisource.org`：调用官方 MediaWiki API 搜索、读取目录与公版或自由许可正文。
- `127.0.0.1:47653`：连接同一安装包中的 DeskFish 本地阅读与窗口贴片引擎；漫画图片代理仍只接受内置来源生成的临时票据，小说接口只读取内置的 Gutenberg 公版书和起点官方公开章节，窗口接口只控制用户在 EXE 中明确选中的顶层窗口，不提供任意网址代理或付费内容绕过。

项目主页：[GitHub · DeskFish](https://github.com/onguoin/DeskFish)
- 可选的 `http://*/*`、`https://*/*`：不会安装时自动取得；仅在用户点击连接 OPDS 服务器时，通过 Edge 权限弹窗授权所选服务器域名及其漫画资源域名。
