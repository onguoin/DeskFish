# DeskFish v0.12.3

## 中文

- 隐藏 Bilibili 外链播放器的“进入哔哩哔哩，观看更高清”入口提示。
- 隐藏持续挡住视频画面的中央加载/暂停图标，不影响视频播放、悬停暂停、进度恢复或直播保活。

解压 `DeskFish-v0.12.3-Windows-x64.zip`，退出旧版托盘程序后运行新的 `DeskFish.exe`，并在 Edge 扩展管理页重新加载压缩包内的 `edge-extension` 文件夹。

## English

- Hides Bilibili's “Open Bilibili for higher quality” entry overlay.
- Removes the persistent center loading/pause chrome without affecting playback, hover pause, resume position, or live keep-alive behavior.

Extract `DeskFish-v0.12.3-Windows-x64.zip`, exit the older tray process, run the new `DeskFish.exe`, and reload the bundled `edge-extension` folder from Edge's extension page.
