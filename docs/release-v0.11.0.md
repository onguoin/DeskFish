## 中文

DeskFish v0.11.0 是首个公开版本：一款为上班摸鱼、午休和办公室无聊时刻准备的 Edge 网页媒体替换、漫画与电子书工具。

- 网页图片/视频替换、悬停显示与原页面瞬时恢复
- Bilibili、虎牙直播、浏览器级复古广告窗与自适应小游戏
- TXT 大文件自动拆分、可调翻页字数/百分比、滚轮逐行阅读与进度记忆
- 本地 CBZ/ZIP/图片、MangaDex、自建漫画库和 DeskFish 本地漫画来源
- 漫画章节连续阅读、页码持久化、前后各 5 页预取与自动缓存释放
- 全新 DeskFish Logo，以及白色/浅青色 Windows 界面

解压后先运行 `DeskFish.exe`，再在 Edge 开发人员模式中加载 `edge-extension` 文件夹。程序为 Windows x64 自包含版本，不需要另装运行时。

## English

DeskFish v0.11.0 is the first public release: an Edge media-replacement, comic, and ebook tool for office downtime, lunch breaks, and quiet moments at work.

- Replace page images/videos, show replacements on hover, and instantly restore the original page
- Bilibili, Huya Live, a browser-level retro ad window, and responsive mini games
- Automatic large-TXT splitting, configurable character/percentage steps, line-by-line wheel reading, and saved progress
- Local CBZ/ZIP/images, MangaDex, self-hosted comic libraries, and DeskFish local sources
- Continuous chapter reading, persistent page position, five-page prefetch on each side, and automatic cache cleanup
- New DeskFish logo and a white/pale-cyan Windows interface

Extract the archive, run `DeskFish.exe`, then load the `edge-extension` folder from Edge Developer mode. This Windows x64 package is self-contained and requires no separate runtime.
