# DeskFish v0.13.0

DeskFish 0.13.0 新增桌面游戏窗口贴片。把窗口化或无边框游戏拖到 `DeskFish.exe` 的投放框内，或从窗口列表选择，即可在 Edge 中把真实可操作窗口贴到任意图片、视频或自建区域。鼠标移开会立刻恢复原图，游戏进程保持运行；恢复页面或退出程序会还原窗口原有样式与位置。

本版本同时支持高 DPI、多显示器与网页滚动后的坐标同步。显示贴片不会主动抢走输入焦点，点击游戏后才会操作；`Alt+Shift+G` 可随时紧急隐藏。独占全屏、权限高于 DeskFish、带反作弊或禁止改窗样式的游戏可能无法使用。

解压 `DeskFish-v0.13.0-Windows-x64.zip`，退出旧版托盘程序后运行新的 `DeskFish.exe`，并在 Edge 扩展管理页重新加载压缩包内的 `edge-extension` 文件夹。

---

DeskFish 0.13.0 adds desktop game window overlays. Drag a windowed or borderless game onto the target in `DeskFish.exe`, or select it from the window list, then place the real interactive window over any image, video, or custom region in Edge. Leaving the area instantly restores the original page image while the game keeps running; restoring the page or exiting DeskFish restores the native window.

This release also handles high-DPI displays, multiple monitors, and page movement. Showing the overlay does not steal focus; click the game to interact. `Alt+Shift+G` is an emergency hide shortcut. Exclusive-fullscreen, elevated, anti-cheat-protected, or style-locked games may not work.

Extract `DeskFish-v0.13.0-Windows-x64.zip`, exit the older tray process, run the new `DeskFish.exe`, and reload the bundled `edge-extension` folder from Edge's extension page.
