# DeskFish v0.12.4

## 中文

- 修复 Bilibili 视频第二次悬停时“进入哔哩哔哩”和中央加载图标重新出现的问题。
- 播放器净化样式现在会在恢复播放、DOM 更新和样式被站点重建后自动恢复，并直接隐藏已经生成的干扰浮层。

解压 `DeskFish-v0.12.4-Windows-x64.zip`，退出旧版托盘程序后运行新的 `DeskFish.exe`，并在 Edge 扩展管理页重新加载压缩包内的 `edge-extension` 文件夹。

## English

- Fixed Bilibili's entry prompt and center loading icon returning on the second hover.
- Player cleanup now restores itself after playback resumes, DOM updates, or site-side style replacement, and directly hides overlays that already exist.

Extract `DeskFish-v0.12.4-Windows-x64.zip`, exit the older tray process, run the new `DeskFish.exe`, and reload the bundled `edge-extension` folder from Edge's extension page.
